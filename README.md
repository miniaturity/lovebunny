## bunniesin.love
> https://bunniesin.love

a puzzle game about two lover bunnies! their hearts are tethered together, but they're seperated.. reunite them to win!

> made with svelte/ts/scss, hosted by cloudflare (pages, workers, R2 storage)

## 🐰 about
bunniesin.love is a puzzle game.. about bunnies in love! centered around 2 seperated bunnies that need to be reunited. they use the same controls, but move opposite of each other. 

inspired by https://enclose.horse 

## 🥕 controls
- Desktop: WASD/Arrow Keys
- Mobile: Arrow Keys (on-screen buttons)

## 🐇 features
| **Feature**              | **Description**                                                                                                                                                                        | **Usage**                   |
|--------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------|
| **Daily Levels**         | _A different puzzle every day! You can only solve a daily puzzle once per day, per user._                                                                                              | -                           |
| **Level Editor**         | _A full level editor! Includes board sizing, a tile palette, tile place preview, solving algorithm, playtesting, and author/level name signing! Supports export/import and uploading._ | Top-left wrench icon.       |
| **User-uploaded Levels** | _You can upload a level you created, as long as it is unique. You cannot upload a level if you hit your daily limit, or if a level already exists that is similar._                    | Upload button in `/editor`. |
| **Solving Algorithm**    | _A built-in solving algorithm that uses BFS to find the optimal solution of any puzzle, if there is one._                                                                              | Editor/Stats                |
| **Tutorial**             | _A full tutorial, going over how to solve most puzzles. Includes a guide dialogue to help you get started!_                                                                            | Top-left help icon.         |
| **Score Histogram**      | _A histogram displaying scores from every user._                                                                                                                                       | Stats button.               |
| **Mobile Compatability** | _Play on mobile using the on-screen arrow keys! You cannot (easily) use the editor, though._                                                                                           | Auto-displays arrow keys.   |
| **Two Cool Bunnies**     | _A white bunny and a brown bunny. They're in love._                                                                                                                                    | Arrow keys/WASD.            |
